# The Meeting That Should Have Been One Line

make.fun bounty entry. The single sentence that could have replaced an entire pointless meeting:

> This meeting could have been an email, and the email could have been nothing.

77 characters, one line, no setup, no explanation.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Writes `entry.txt` to the output directory and verifies it by reading it back.
